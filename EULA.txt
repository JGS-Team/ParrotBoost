4. SYSTEM MODIFICATIONS & DISCLAIMER OF WARRANTY
================================================================================

ParrotBoost performs advanced Windows system and registry operations when configured or triggered by the User. Depending on enabled options, this may include:
- Creating and activating power schemes ("Turbo Parrot"), adjusting core parking, frequency limits, turbo boost mode, and USB selective suspend.
- Managing Windows services, scheduled tasks (including optional elevated startup task "ParrotBoostStartup"), dynamic tick BCD settings (`bcdedit`), NTFS last-access timestamps, and low-latency network/priority settings.
- Adjusting Windows timer resolution (0.50 ms HighQoS), purging standby memory lists, and temporarily lowering background process priorities.
- Applying Windows privacy and Microsoft AI / Copilot / Recall / Edge policy keys in HKLM/HKCU.
- Cleaning stale temporary files, Windows Update download cache, crash dumps, thumbnail databases, browser caches, system logs, or Recycle Bin items when selected.

Before applying system tweaks, you are responsible for reviewing selected options and maintaining appropriate backups. System modifications are reversible through the "Slow Down" / restore workflow or "Restore Factory Defaults", subject to Windows permissions.

5. HARDWARE TELEMETRY & NETWORK PRIVACY
================================================================================

- Local Telemetry: ParrotBoost reads CPU, multi-GPU / iGPU, RAM, disk, and PnP device diagnostics locally via Win32 APIs, WMI, and LibreHardwareMonitor. This data never leaves your device.
- Driver & Update Checks: ParrotBoost queries public GitHub Releases API (comparing version 3.0.4 against the latest published release) and public GPU vendor endpoints (NVIDIA, AMD, Intel) solely to check version availability. No personal information, hardware identifiers, or usage analytics are collected or transmitted to JGS-Team.
- Updates: Initiated only when you choose "Update Now", downloading and launching the elevated Inno Setup installer (`ParrotBoost-Setup-x64.exe`). Automatic startup update checks can be toggled in General settings.
